# KiLibSync

GitHub上のKiCadライブラリなどを、ローカルにクローンして一括更新するGUIツールです。

## 起動

Python 3.10以降（Tkinterを含む）とGitをインストールし、どちらもPATHから実行できる状態にします。
Windowsでは `start.bat` をダブルクリックするか、次のコマンドで起動します。

```powershell
python kilibsync.py
```

## 使い方

1. 「ライブラリを追加」でGitHubのURLとローカルリポジトリのパスを指定します。
   HTTPSとSSHのURLに対応しています。リポジトリ名はURLから自動取得します。
   「参照…」では親フォルダーを選ぶと、リポジトリ名を付けた保存先が入力されます。
2. 新規の保存先にはクローンします。既存フォルダーの場合はリポジトリのルートとorigin URLの一致を確認します。
3. 「すべてプル」で登録済みリポジトリを順番に更新します。
   成功日時をタイムゾーン付きで保存します。クローン直後は「未実行」と表示します。
4. 削除する場合は一覧の行を選び、「選択した登録を削除」を押します。
   複数選択に対応しています。ローカルファイルは削除しません。

更新には `git pull --ff-only` を使います。履歴が分岐している場合は失敗を表示するため、Gitで解決してください。
エラーが発生しても他のリポジトリの更新を続けます。各Gitコマンドのタイムアウトは5分です。
非公開リポジトリでは、事前にGitの認証やSSH鍵を設定してください。GUIから認証情報を入力する機能はありません。

登録情報はWindowsでは `%LOCALAPPDATA%\KiLibSync\repositories.json` に保存します。
KiCadのライブラリテーブルへの登録は、このツールとは別にKiCadで行ってください。

## 検証

```powershell
python -m unittest -v
```

一時的なローカルGitリポジトリを使って、クローン、プル、origin検証、URL解析、設定保存を検証します。
