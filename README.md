# KiLibSync

GitHub上のKiCadライブラリなどを、ローカルにクローンして一括更新するGUIツールです。

## 起動

Windows向けのexe化した配布版を [GitHub Releases](https://github.com/cotechworks/KiLibSync/releases) に公開しています。
Releaseの添付ファイルをダウンロードし、アーカイブの場合は展開してから `KiLibSync.exe` を起動してください。
配布版ではPythonのインストールは不要ですが、GitをインストールしてPATHから実行できる状態にする必要があります。
フォルダー形式の配布版では、同梱ファイルをまとめて配置してください。

ソースコードから起動する場合は、Python 3.10以降（Tkinterを含む）とGitが必要です。追加のPythonパッケージは不要です。
Windowsでは `start.bat` をダブルクリックすると、`.venv` があればそのPythonを使い、なければPATH上のPythonで起動します。
コマンドで起動する場合は次のように実行します。

```powershell
python kilibsync.py
```

仮想環境を作成して起動する場合は次のコマンドを使用します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe kilibsync.py
```

exeを自分でビルドする場合は、`.venv` にNuitkaをインストールして `build.bat` を実行します。
ビルドにはCコンパイラが必要です。現在のバッチはstandaloneモードで、
`build\kilibsync.dist\KiLibSync.exe` を生成します。配布する際は `kilibsync.dist` フォルダー全体を含めてください。

```powershell
.\.venv\Scripts\python.exe -m pip install nuitka
.\build.bat
```

## 使い方

一覧には「リポジトリ名」「ローカルリポジトリのパス」「最後に更新した日時」を表示します。

1. 「ライブラリを追加」でGitHubのURLとローカルリポジトリのパスを指定します。
   HTTPSとSSHのURLに対応しています。リポジトリ名はURLから自動取得します。
   URLは `https://github.com/所有者/リポジトリ` または `git@github.com:所有者/リポジトリ.git` の形式で入力してください。
   「参照…」では親フォルダーを選ぶと、リポジトリ名を付けた保存先が入力されます。
2. 新規の保存先や空のフォルダーにはクローンします。既存の空でないフォルダーの場合はリポジトリのルートとorigin URLの一致を確認します。
   同じローカルパスは重複して登録できません。
3. 一覧表の下にある「すべて更新」で登録済みリポジトリを順番に更新します。
   成功日時をタイムゾーン付きで保存します。クローン直後は「未実行」と表示します。
4. 編集する場合は一覧の行を1件選び、「選択した登録を編集」を押します。
   URLとローカルパスを変更できます。名前はURLから自動取得します。
   編集先にはURLとoriginが一致する既存リポジトリを指定してください。
   編集時の「参照…」では、既存リポジトリのフォルダーそのものを選択します。
   ファイルの移動やoriginの変更は行いません。URLまたはパスを変更すると最終更新日時をリセットします。
5. 削除する場合は一覧の行を選び、「選択した登録を削除」を押します。
   複数選択に対応しています。ローカルファイルは削除しません。

更新には `git pull --ff-only` を使います。履歴が分岐している場合は失敗を表示するため、Gitで解決してください。
Gitの更新に失敗した場合はログに表示し、他のリポジトリの更新を続けます。失敗したリポジトリの最終更新日時は変更しません。
処理結果は画面下部のログに表示します。処理中は操作ボタンが無効になり、完了してから終了できます。
各Gitコマンドのタイムアウトは5分です。
非公開リポジトリでは、事前にGitの認証やSSH鍵を設定してください。GUIから認証情報を入力する機能はありません。

登録情報はexeと同じフォルダーの `repositories.json` に保存します。
Pythonで起動する場合は `kilibsync.py` と同じフォルダーに保存します。
保存する情報はリポジトリ名、URL、ローカルパス、最終更新日時です。保存先は書き込み可能なフォルダーを使用してください。
exeを別のフォルダーに移す際は `repositories.json` も一緒に移すと登録を引き継げます。
ライブラリ本体は指定したローカルパスに残るため、別のPCへ移行する場合はライブラリ本体のコピーとパスの調整も必要です。
既存の登録情報を引き継ぐ場合は `%LOCALAPPDATA%\KiLibSync\repositories.json` を新しい保存先へコピーしてください。
KiCadのライブラリテーブルへの登録は、このツールとは別にKiCadで行ってください。

## 検証

```powershell
python -m unittest -v
```

`.venv` を使う場合は `.\.venv\Scripts\python.exe -m unittest -v` を実行してください。

5件のテストで、URL解析、設定の保存、Python・standalone・onefileの保存先、編集ダイアログの保存と失敗時のデータ保持を検証します。
クローン、プル、originとリポジトリルートの検証には一時的なローカルGitリポジトリを使うため、GitHubへの接続は不要です。
Tkinterを起動できない環境では、編集ダイアログのテストをスキップします。
